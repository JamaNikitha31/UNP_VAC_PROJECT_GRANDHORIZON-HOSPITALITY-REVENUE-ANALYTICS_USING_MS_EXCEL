# UNP_VAC_PROJECT_GRANDHORIZON-HOSPITALITY-REVENUE-ANALYTICS_USING_MS_EXCEL

GrandHorizon Hospitality Revenue Analytics – In Collaboration with UNP Education

Completed a data analytics project using Microsoft Excel with both manual and AI-assisted approaches. Created charts, plots, and interactive dashboards to analyze average daily rate, cost per room, gross operating profits lakhs  in data analytics and business insights.
